# Aurora Health Lakehouse

## Overview

Aurora Health Lakehouse is a fictitious enterprise-grade Data Engineering project designed to simulate how a healthcare organization ingests, processes, and serves clinical and financial data using the Databricks Lakehouse Platform.

The project follows modern Data Engineering practices including:

- Medallion Architecture
- Unity Catalog
- Databricks Asset Bundles (DABs)
- Incremental ingestion
- Change Data Capture (CDC)
- Delta Lake
- Data Quality
- Scalable data pipelines

Although the project uses the Synthea synthetic healthcare dataset, the architecture is designed to support real-world healthcare systems and future integration with APIs, streaming pipelines, and bioinformatics datasets.

---

# Business Problem

Aurora Health Network receives healthcare data from multiple operational systems every day.

Clinical and financial records arrive continuously and must be:

- centralized
- validated
- versioned
- transformed
- governed
- made available for analytics and future Machine Learning workloads.

The objective of this project is to build the foundational Lakehouse architecture capable of supporting these requirements.
